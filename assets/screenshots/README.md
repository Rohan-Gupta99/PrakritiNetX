# Screenshots & Prototype Photos

This folder contains important screenshots, hardware prototype photos, and visual documentation for the PrakritiNetX project.

---

## Naming Convention

Use clear, descriptive filenames:

| Type | Example Filename |
|---|---|
| Hardware prototype | `hardware_lite_node_assembled.jpg` |
| PCB layout | `pcb_vision_tier_top.png` |
| Field deployment | `field_deployment_alaknanda.jpg` |
| Mobile app screen | `fieldflash_wizard_step1.png` |
| Dashboard UI | `dashboard_realtime_alerts.png` |
| ML model output | `waternet_segmentation_output.png` |
| Architecture diagram | `system_architecture_overview.png` |
